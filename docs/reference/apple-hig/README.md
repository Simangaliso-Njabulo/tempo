# Apple Human Interface Guidelines — local snapshots

These 36 pages were downloaded on **2026-10-25** from Apple’s Markdown endpoints:

## Refresh

From the repository root:

```powershell
pwsh docs/reference/apple-hig/refresh.ps1
```

The script downloads the 36 pages again and overwrites the local snapshots. Review the diff before committing. If Apple changes a rule that affects TEMPO, update the design contract and decision log.

## What to do when the HIG and the product disagree

- The HIG is a platform convention, not a legal requirement. A deliberate deviation is allowed when it serves the product and is documented.
- If the deviation affects accessibility, err on the side of the HIG and WCAG.
- Record the trade-off in `docs/design/decisions.md`.
- If the HIG snapshot is stale, refresh it before making the decision.
