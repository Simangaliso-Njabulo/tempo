# Features

One page per feature. Each has a sequence diagram (who talks to whom) and a flowchart (how the data moves), plus the real files and the `DomainError` codes you can hit.

| Feature | What it proves |
|---|---|
| [Brain dump](brain-dump.md) | A title becomes a task in the tray |
| [Placement](placement.md) | A task becomes a block, later blocks shift |
| [Drag](drag.md) | Pointer Events move a block, one commit at pointer up |
| [Routines](routines.md) | Due, placed once, skippable per day |
| [Reflow](reflow.md) | An overrun shifts the rest of the day, previewed first |
| [Close day](close-day.md) | Unfinished work returns to the inbox or is let go |
| [Carry over](carry-over.md) | Midnight moves unfinished work quietly |
| [Undo](undo.md) | Every write is preceded by a snapshot |
| [Backup](backup.md) | Export, encrypt, import, replace or merge |
| [Calendar export](calendar.md) | One day to `.ics` with an alarm |
| [Settings](settings.md) | Theme, time format, routines, storage |
| [Offline](offline.md) | Precache, install prompt, update toast |
