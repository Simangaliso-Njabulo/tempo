# Install TEMPO on iPhone

1. Open the TEMPO page in Safari: <https://simangaliso-njabulo.github.io/tempo/>
2. Tap **Share**.
3. Tap **Add to Home Screen**.
4. Leave **Open as Web App** on (iOS 26 turns it on by default).
5. Tap **Add**.
6. Open TEMPO from the Home Screen.

The Home Screen app is the supported experience. It keeps the timeline and tray clear of browser chrome and works offline after the first load.

TEMPO never shows this hint on first launch. After the second block is planned, a small line appears in the tray footer. Dismiss it with the **×** or choose **Don't show again** in the sheet.

## Updates

When a new version is ready, TEMPO shows **New version ready** with **Reload** and **Later**. TEMPO never reloads while you are typing or inside a sheet. Tap **Reload** when you are ready.

## Offline

TEMPO stores your day in the browser on this iPhone. It does not need a network connection after the app shell is cached. Back up before clearing Safari data or changing devices.
