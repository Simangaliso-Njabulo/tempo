# Superpowers artifacts

The final product spec and implementation plan are written **after** the combined design package is approved. Do not start implementation before both exist and are approved.

## Planned paths

- Spec: `docs/superpowers/specs/2026-10-25-tempo-design.md` — the approved product, UX, architecture, data, quality, and loop contract.
- Plan: `docs/superpowers/plans/` — the ordered implementation plan with review checkpoints.

## Approval gate

1. The user approves or revises the design package, including the reflow default and the Part 4 defaults.
2. The spec is written from the approved package and the decision log.
3. The spec is self-reviewed and approved by the user.
4. The implementation plan is written and approved.
5. Implementation begins.

## Reference rule

The spec must cite the relevant decision IDs and reference notes. If the spec and the reference library disagree, update one of them deliberately before writing code.
