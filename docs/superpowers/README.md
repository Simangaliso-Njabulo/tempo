# Superpowers artifacts

The final product spec and implementation plans are written **after** the combined design package is approved. The app and operations plans are complete and awaiting approval; do not start implementation before both are approved.

## Planned paths

- Spec: `docs/superpowers/specs/2026-10-25-tempo-design.md` — the approved product, UX, architecture, data, quality, and loop contract.
- Plans: `docs/superpowers/plans/` — the ordered app and operations plans with review checkpoints (complete, awaiting approval).

## Approval gate

1. The design package is approved (D-028, 2026-10-25).
2. The spec is written from the approved package and the decision log.
3. The spec is self-reviewed and approved by the user (2026-10-25).
4. The app and operations plans are written (2026-10-25); awaiting user approval.
5. Implementation begins only after approval.

## Reference rule

The spec must cite the relevant decision IDs and reference notes. If the spec and the reference library disagree, update one of them deliberately before writing code.
